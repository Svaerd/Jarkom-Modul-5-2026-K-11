=== SOAL 10: SABOTASE break_nat.sh DI MISATO DAN GENDO ===

--- Dua penyebab yang ditemukan ---
1. Di Misato (tabel nat POSTROUTING): rule '-A POSTROUTING -s 10.69.4.64/29 ! -d 10.69.0.0/16 -o eth0 -j SNAT --to-source 172.31.99.1'.
   Saat menuju internet, IP sumber Switch-Cage langsung diubah Misato menjadi 172.31.99.1 sehingga tidak lagi cocok dengan 10.69.0.0/21 di firewall FORWARD dan MASQUERADE Gendo.
   Traffic Cage -> Lilith (10.69.4.74) tidak terkena karena ! -d 10.69.0.0/16 mengecualikan tujuan jaringan internal.
2. Di Gendo (tabel nat POSTROUTING): rule '-A POSTROUTING -s 10.69.4.64/29 -o eth0 -j RETURN' tepat di atas MASQUERADE.
   Jika hanya Misato yang dibersihkan, paket Cage keluar melewati Gendo eth0 tanpa NAT (karena RETURN keluar dari chain sebelum MASQUERADE).
3. Kenapa Cage terdampak tapi Intel (Spy) tidak: kedua rule menarget spesifik prefix 10.69.4.64/29 (Switch-Cage) dan Spy berada di cabang Kaji (10.69.4.100/30).
4. Di router mana alamat sumber diterjemahkan: saat sabotase di Misato (menjadi 172.31.99.1); pada kondisi normal setelah perbaikan, terjemahan sumber hanya di Gendo (MASQUERADE keluar eth0).

--- State tabel nat setelah perbaikan ---
Misato:
-P PREROUTING ACCEPT
-P INPUT ACCEPT
-P OUTPUT ACCEPT
-P POSTROUTING ACCEPT

Gendo (nat & filter):
-P PREROUTING ACCEPT
-P INPUT ACCEPT
-P OUTPUT ACCEPT
-P POSTROUTING ACCEPT
-A POSTROUTING -s 10.69.0.0/21 -o eth0 -j MASQUERADE
-P INPUT DROP
-P FORWARD DROP
-P OUTPUT ACCEPT
-A INPUT -i lo -j ACCEPT
-A INPUT -m conntrack --ctstate RELATED,ESTABLISHED -j ACCEPT
-A INPUT -i eth0 -p udp -m udp --sport 67 --dport 68 -j ACCEPT
-A INPUT -s 10.69.0.0/21 ! -i eth0 -j ACCEPT
-A FORWARD -m conntrack --ctstate RELATED,ESTABLISHED -j ACCEPT
-A FORWARD -s 10.69.0.0/21 ! -i eth0 -o eth0 -j ACCEPT
-A FORWARD -s 10.69.0.0/21 -d 10.69.0.0/21 ! -i eth0 ! -o eth0 -j ACCEPT
