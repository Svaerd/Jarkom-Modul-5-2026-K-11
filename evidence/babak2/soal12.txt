=== SOAL 12: SABOTASE break_fw.sh DI MAGI-CASPER ===

--- Empat penyebab yang ditemukan ---
1. Policy INPUT diubah ke DROP tanpa mengizinkan conntrack ESTABLISHED,RELATED (balasan ping 8.8.8.8, balasan DNS/HTTP apt-get ter-drop).
2. Rule '-A INPUT -p icmp -j DROP' memblokir seluruh protokol ICMP (bukan hanya echo-request).
3. Tidak ada rule izin masuk TCP port 5000 pada INPUT (Unit-00 gagal mengakses layanan Casper).
4. Rule '-A OUTPUT -p udp --dport 53 -j DROP' memblokir query DNS keluar dari Magi-Casper (apt-get update gagal resolve deb.debian.org).

--- iptables -S @ Magi-Casper setelah perbaikan (idempoten 2x run) ---
-P INPUT DROP
-P FORWARD DROP
-P OUTPUT ACCEPT
-A INPUT -i lo -j ACCEPT
-A INPUT -m conntrack --ctstate RELATED,ESTABLISHED -j ACCEPT
-A INPUT -p tcp -m tcp --dport 5000 -j ACCEPT
-A INPUT -p icmp -m icmp --icmp-type 8 -j DROP

--- Unit-00 -> Casper TCP 5000 ---
exit=0
